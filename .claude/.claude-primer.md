# 🇨🇦 Canadian Rep Finder - Quick Primer

**🎯 TL;DR: This React/Capacitor mobile app has been CONVERTED FROM R to TypeScript for superior Canadian postal code support.**

## ✅ **CURRENT STATE: R-CODE IS ACTIVE**

### **Search Methods (ALL use R-converted code):**
- **Postal Code**: `fetchRepsByPostalR()` → R-geocoding → Enhanced Canadian accuracy
- **Name Search**: `fetchRepsByNameR()` → R-processing + proper Federal→Provincial→Municipal sorting
- **Location**: R-based coordinate search with multiple geocoding fallbacks

### **Key Files:**
- `client/src/lib/rSearchService.ts` - **MAIN R SERVICE**
- `client/src/lib/rGeocodeSearch.ts` - **R GEOMETRY LOGIC** (converted from R)
- `client/src/components/search-form.tsx` - **R-FIRST PRIORITY** (lines 97-98)
- `client/src/pages/name-search.tsx` - **R-BASED NAME SEARCH** (line 61)

### **Mobile App Status:**
- ✅ **Standalone** - runs completely on phone (no dev server needed)
- ✅ **R-Enhanced** - all search methods use converted R logic
- ✅ **Cache Updated** - `SEARCH_CACHE_R_V2` invalidates old API data

## 🔄 **WHEN MAKING CHANGES:**

### **✅ ALWAYS USE:**
```javascript
import { fetchRepsByPostalR, fetchRepsByNameR } from "@/lib/rSearchService";
```

### **❌ NEVER USE OLD API (except fallbacks):**
```javascript
// OLD - Don't use as primary method
import { fetchRepsByPostal, fetchRepsByName } from "@/lib/representApi";
```

### **🚀 Build Commands:**
```bash
npm run build && npx cap sync  # Deploy changes to mobile
npm run dev                     # Development server (localhost:5001)
```
