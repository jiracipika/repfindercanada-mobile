# Canadian Representative Finder - Project Context

## 🎯 Project Overview
Canadian mobile app (iOS/Android) built with React + Capacitor that helps users find their government representatives by postal code, location, or name. The app has been **converted from R to TypeScript** for better Canadian postal code support.

## 🏗️ Architecture
- **Frontend**: React (client/src) with TypeScript
- **Backend**: Express.js (server/) with PostgreSQL database
- **Mobile**: Capacitor for iOS/Android apps
- **Shared Types**: TypeScript definitions in shared/

## 🔄 R-Code Conversion (MAJOR CHANGE)

### ✅ **Postal Code Search: Uses R-Converted Code**
- **Primary Method**: `fetchRepsByPostalR()` in `client/src/lib/rSearchService.ts`
- **R Logic**: `getRepsFromAddress()` in `client/src/lib/rGeocodeSearch.ts`
- **Enhanced Geocoding**: Multiple Canadian services (geocoder.ca, OpenCage, postalcodecsv.com, Nominatim)
- **Cache**: Updated to `SEARCH_CACHE_R_V2` to invalidate old API data
- **Priority**: R-based search runs FIRST, official sources as fallback

### ✅ **Name Search: Uses R-Enhanced Code**
- **Primary Method**: `fetchRepsByNameR()` in `client/src/lib/rSearchService.ts`
- **R Processing**: Applies R-style data structure and sorting logic
- **Sorting**: Federal (MP) → Provincial (MPP/MLA/MNA) → Municipal (Mayor/Councillor)
- **Consistent**: Same R logic as postal code search

### 🚀 **App is Standalone (No Dev Server Required)**
- **Mobile App**: Self-contained, runs entirely on device
- **External APIs Only**: geocoder.ca, nominatim.openstreetmap.org, represent.opennorth.ca
- **Capacitor Config**: Updated for standalone mode (`capacitor.config.ts`)

## 🎯 Current Search Flow

### **Postal Code Search:**
```javascript
1. Try R-based search first (fetchRepsByPostalR)
2. If R fails → fallback to official sources (House of Commons API)
3. Cache results with SEARCH_CACHE_R_V2 key
4. Enhanced Canadian postal code support with special case handling
```

### **Name Search:**
```javascript
1. Use R-enhanced name search (fetchRepsByNameR)
2. Apply R-style data processing and sorting
3. Federal → Provincial → Municipal priority
4. Consistent with postal code search logic
```
